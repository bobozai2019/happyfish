## 执行规则

1. 开始任务前在 `../执行状态.md` 将任务和当前小目标标为 `[进行中]`，登记 Active Lock。
2. 每次只允许一个执行者修改 `project.godot`、主场景、HUD/暂停/结果场景或对应控制器。
3. T01 通过后契约 frozen；后续改动必须记录 ADR，不得静默改变边界。
4. 每个任务完成时逐项更新小目标、运行验收命令，并把实际结果写入 `../验收/`。
5. 旧任务 `task/happy_fish/` 为历史执行记录，不修改其状态或验收报告。
6. 若使用 subagent，必须复制任务细则中的目标、允许/禁止路径、验收和回报格式；没有用户授权时由主 agent 串行执行。

## 标准回报格式

- 完成内容
- 修改文件
- 小目标进度
- 验证命令与结果
- 契约变化
- 风险与遗留
- 验收证据路径
