## 2. MVP 边界

### 必须完成

1. 启动后显示模式选择：单人捕鱼或双人同乐，确认后才创建并启动单局。
2. 单人模式仅创建玩家 1，一座炮台位于底部中央，只显示单人 HUD 和单人结果。
3. 单人模式可选择鼠标或键盘；默认选中鼠标，暂停时允许即时切换。
4. 单人鼠标：指针瞄准、左键点按/长按开火、HUD `－`/`＋` 换挡和开炮按钮。
5. 单人键盘：继续使用 P1 的 `A/D`、`W/S`、`Space`。
6. 双人模式固定使用现有双键盘映射，不显示操作方案选择或鼠标操作按钮。
7. 单人保留 120 初始金币、一次 30 金币救援、个人保底；第二次耗尽后直接结算。
8. 单人 Boss 首次捕获数阈值为 10，双人保持 18；60 秒时间阈值、2 秒预告和 90 秒冷却不变。
9. 重新开始保持当前游戏模式和单人操作方式；返回模式选择会销毁并重置当前单局。
10. Windows 与桌面 Web 的模式选择、单人鼠标、单人键盘和双人键盘回归通过。

### 占位但不作为成品验收

1. 模式选择和鼠标按钮使用现有主题、字体、图标和美漫卡通原型质量，可后续替换正式素材。

### vNext

1. 手柄、触控、虚拟摇杆、移动端安全区。
2. 可重映射按键、灵敏度、左右手鼠标布局和辅助瞄准强度。
3. 单人专属数值难度、鱼群密度或独立关卡。
4. 永久保存上次模式和操作方式。

### 明确不做

1. 双人鼠标或双人操作方案选择；双人始终为现有双键盘。
2. 修改鱼类奖励、炮倍概率、保底公式或双人经济。
3. 账号、存档、网络、排行榜、广告、商店或真实货币。
4. 手机浏览器、Firefox、Safari 或线上托管验收。

## 6. 谨慎并发窗口

允许并发：

1. Gate 1 冻结后，可并行准备不修改场景的测试夹具和模式选择视觉素材。
2. T03 内部 typed session 逻辑测试可与不修改 `session_state.gd` 的场景草图并行。
3. T06 中 Windows smoke、Web 静态文件检查和文档核对可在构建产物固定后并行。

禁止并发：

1. 多个执行者同时修改 `scenes/game/main.tscn`、`scripts/game/session_state.gd` 或 `scripts/ui/ui_controller.gd`。
2. 输入契约未冻结时，同时修改 `CannonController`、输入路由和 HUD 按钮信号。
3. T04 与 T05 同时修改 `hud.tscn`、`pause_overlay.tscn` 或 UI 控制器。
4. 验收阶段直接修改玩法数值来掩盖模式或输入失败。

默认由主 agent 严格按 DAG 串行执行；只有用户明确要求 subagent 时才启用并发。
