# T04 输入路由验收

文档角色：`verification_evidence`

状态：[已完成]

日期：2026-08-08

## 完成内容

- 新增 `PlayerInputRouter`，作为原始键盘、鼠标与 Cannon 命令 API 的唯一桥梁。
- `CannonController` 不再读取 `Input`，改为 keyboard axis、world aim、level change、fire held 和 fire once 命令。
- 单人鼠标支持指针瞄准、左键立即一发、按 0.25 秒冷却连发和全局释放。
- 单人键盘复用 P1 映射；双人继续固定两套键盘，鼠标不控制任一炮台。

## 输入释放触发点

1. 左键在任意位置释放。
2. Session 从 RUNNING 进入 PAUSED 或 RESULTS。
3. 单人鼠标/键盘操作方式切换。
4. GameFlow 重开当前局。
5. 返回模式选择 / InputRouter 离开 SceneTree。
6. 应用窗口失焦。
7. `set_enabled(false)` 与 Cannon `input_enabled=false`。
