# 游戏模式与流程契约

文档角色：`contract`

状态：`frozen`（T01 / Gate 1）

Owner：T01/T02/T03

## 1. `GameSessionConfig`

实现形式：typed `RefCounted`，建议路径 `scripts/data/game_session_config.gd`。仅存在于当前进程内，不序列化。

### 枚举

```gdscript
enum GameMode {
	SINGLE_PLAYER,
	LOCAL_COOP,
}

enum SinglePlayerControl {
	MOUSE,
	KEYBOARD,
}
```

### 字段

| 字段 | 类型 | 必填 | 默认 | 校验 | 说明 |
|---|---|---:|---|---|---|
| `game_mode` | `GameMode` | 是 | `SINGLE_PLAYER` | 枚举合法值 | 当前单局人数模式 |
| `single_player_control` | `SinglePlayerControl` | 是 | `MOUSE` | 枚举合法值 | 仅单人模式消费 |

### 只读派生 API

| 方法 | 返回 | 规则 |
|---|---|---|
| `get_active_player_ids()` | `Array[int]` | 单人 `[1]`；双人 `[1, 2]`，返回副本 |
| `is_single_player()` | `bool` | `game_mode == SINGLE_PLAYER` |
| `uses_mouse(player_id)` | `bool` | 仅单人、玩家 1、control 为 `MOUSE` 时为 true |
| `duplicate_config()` | `GameSessionConfig` | 返回字段值相同的新实例，禁止跨单局共享可变引用 |
| `validate()` | `PackedStringArray` | 合法时为空；枚举非法时返回稳定、可测试的中文错误列表 |

双人模式忽略 `single_player_control`，不得据此启用鼠标输入或隐藏任一键盘玩家。

构造与失败规则：默认构造必须得到“单人 + 鼠标”；调用者可直接赋值两个枚举字段，但进入 `start_game()` 或 `configure()` 前必须通过 `validate()`。非法配置不得被静默修正。

## 2. 应用流程状态

应用层状态与现有 `SessionState.State` 分离：

```gdscript
enum AppState {
	MODE_SELECT,
	PLAYING,
}
```

合法转换：

```text
MODE_SELECT → PLAYING   # 玩家确认配置，创建战斗实例
PLAYING → MODE_SELECT   # 玩家确认返回，销毁战斗实例
```

禁止在应用层增加 `PAUSED` 或 `RESULTS`；这些仍属于单局状态机。

## 3. `GameFlowController` 内部 API

建议路径：`scripts/app/game_flow_controller.gd`，附着于 `scenes/main.tscn`。

### 字段与节点

| 名称 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `app_state` | `AppState` | 是 | 初始为 `MODE_SELECT` |
| `last_selection` | `GameSessionConfig` | 是 | 进程内保存最近选择，初始单人鼠标 |
| `mode_select` | `Control` | 是 | 预制模式选择实例 |
| `game_container` | `Node` | 是 | 当前战斗实例父节点 |
| `current_game` | `Node` | 否 | PLAYING 时唯一实例 |
| `battle_scene` | `PackedScene` | 是 | 固定为可配置战斗场景；加载失败时不得切换状态 |

### 方法

| 方法 | 输入 | 返回 | 前置条件 | 后置条件 |
|---|---|---|---|---|
| `start_game(config)` | `GameSessionConfig` 非空 | `bool` | `MODE_SELECT` | 复制配置、实例化战斗、配置 Session、进入 PLAYING |
| `return_to_mode_select()` | 无 | `void` | `PLAYING` | 释放战斗、清空引用、显示选择页、进入 MODE_SELECT |
| `restart_current_game()` | 无 | `bool` | `PLAYING` | 复用当前配置重置单局，不回选择页 |
| `update_single_control(control)` | 合法枚举 | `bool` | PLAYING 且单人 | 清理旧输入，更新当前 config、last_selection、路由和 UI；不重置单局 |

### 信号

| 信号 | 参数 | 时机 |
|---|---|---|
| `app_state_changed` | `old_state:int, new_state:int` | 合法转换完成后 |
| `game_started` | `config:GameSessionConfig` | 战斗实例完成配置并可运行后 |
| `game_returned_to_select` | 无 | 战斗实例释放并显示选择页后 |
| `single_control_changed` | `old_control:int, new_control:int` | 单人操作切换成功并清理 held 后 |

失败返回约定：前置条件不满足或配置非法时返回 `false`、保持原状态，并在开发运行中使用 `push_error()` 输出原因；不得部分创建场景或部分更新配置。重复切换到当前 control 返回 `true`，但不重复发射信号。

## 4. 模式选择控制器契约

建议路径：`scripts/ui/mode_select_controller.gd`，附着于 `scenes/ui/mode_select.tscn`。

| API | 参数/返回 | 规则 |
|---|---|---|
| `selection_confirmed` 信号 | `config:GameSessionConfig` | 点击开始且当前选择合法时发射配置副本 |
| `set_selection(config)` | `GameSessionConfig -> void` | 从 last_selection 刷新卡片、单人 control 和说明 |
| `get_selection()` | `GameSessionConfig` | 返回当前 UI 选择的副本 |
| `show_error(message)` | `String -> void` | 展示可恢复启动错误，不切换页面 |

稳定节点语义：`SingleModeButton`、`CoopModeButton`、`MouseControlButton`、`KeyboardControlButton`、`StartButton`、`ErrorLabel`。节点可嵌套，但名称不得在 T02-T06 静默改变。

## 5. 场景生命周期

1. `project.godot` 主场景改为 `res://scenes/main.tscn`。
2. `scenes/main.tscn` 静态包含模式选择层和战斗容器；不在脚本中重建选择 UI。
3. 应用启动时不得提前实例化 `scenes/game/main.tscn`，因此不得生成鱼、播放战斗 BGM 或推进 Boss 时间。
4. `start_game()` 实例化唯一战斗场景，在加入 SceneTree 前调用其 `Session` 子节点的 `configure(config)`；配置成功后才加入 `game_container`。
5. `return_to_mode_select()` 必须释放整棵战斗实例；不得只隐藏游戏画面。
6. 重新开始只调用配置化单局重置，保留模式与单人操作方式。

## 6. 模式选择 UI 状态

| 选择 | 单人操作选择 | 操作说明 | 开始按钮 |
|---|---|---|---|
| 单人 | 可见且可用，默认鼠标 | 显示鼠标或 P1 键盘提示 | 可用 |
| 双人 | 隐藏或禁用 | 显示双方固定键盘映射 | 可用 |

选择双人时不得改变存放在 `last_selection` 中的最近单人操作偏好；再次选择单人时恢复该进程内偏好。

## 7. 重开与返回语义

| 动作 | 配置 | 玩家状态 | 鱼/子弹/网 | 应用状态 |
|---|---|---|---|---|
| 重新开始 | 保留 | 重建 | 全清 | PLAYING |
| 结果页再来一局 | 保留 | 重建 | 全清 | PLAYING |
| 返回模式选择 | 进程内记忆 | 销毁 | 随战斗实例销毁 | MODE_SELECT |
| 关闭应用 | 不保存 | 销毁 | 销毁 | 下次恢复默认 |

返回模式选择必须经过确认；结果页返回可直接执行或共用确认层，但不得留下当前局状态。

## 8. 失败模式

- config 为空或枚举非法：开发构建报错，拒绝开始游戏。
- PLAYING 已有实例时再次 start：拒绝并返回 false，不生成第二实例。
- 切换单人操作时处于双人模式：拒绝并保持双键盘。
- 战斗场景加载失败：保持 MODE_SELECT，并显示可恢复错误提示。
- 返回选择释放后仍存在鱼、音频或计时：Gate 2 失败。
