## 验收标准

1. `tests/run_all.gd` 和 headless 启动退出码为 0。
2. 双人连续游玩 10 分钟无卡死、输入串线、重复发奖或负金币。
3. 当前开发机压力场景接近 60 FPS，无持续低于 55 FPS。
4. Windows 调试构建可独立运行。
5. Web 构建在桌面 Chrome、Edge 中正常运行、无页面滚动、首次交互后有声音。
6. 所有 P0 需求在 `需求映射.md` 中链接到实际证据。
