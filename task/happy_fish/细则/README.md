执行规则：

1. 开始任务前在 `../执行状态.md` 登记 `[进行中]`、负责人和 Active Lock。
2. 契约为 frozen 后不得直接改动；需要变化时先更新 `../决策记录.md` 并重新过 Gate 1。
3. 完成任务必须逐项更新小目标状态，并把实际结果写入 `../验收/`。
4. 回报至少包含：完成内容、修改文件、Gxx 状态、验证命令与结果、契约变化、风险遗留、证据路径。
5. 未明确授权并行 agent 时，全部任务由主 agent 按依赖顺序执行。
