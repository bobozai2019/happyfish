## 2. 布局与视觉

1. P1 HUD 位于左上，使用暖色玩家标识；P2 HUD 位于右上，使用冷色玩家标识。
2. 倍率和金币使用大字号、高对比、图标加文本，避免只依赖颜色区分。
3. 常驻显示双方控制提示；提示不得遮挡主要鱼群区域。
4. 暂停和结果层为预制 `.tscn`，使用 `CanvasLayer`、容器和锚点。
5. 捕获反馈包含金币飘字、短特效和音效；同一奖励只显示一次。
6. 全部玩家文案使用简体中文，语气积极，不展示“破产”“失败”等词。
7. 美术统一美漫卡通：粗轮廓、高饱和对比色、夸张比例与赛璐璐式明暗。

## 3. 音频

- 必须有：1 条可循环 BGM、开炮、命中/张网、捕获、Boss 提示、按钮音效。
- 两位玩家可使用轻微音高或声像差异帮助区分，但不得造成音量不平衡。
- 同帧大量捕获时限制重叠音效数量，避免爆音。
- Web 首次交互前音频未启动不视为错误；首次有效操作后必须开始。

## 4. E2E 场景

### E2E-01 双人同时操作

1. 启动项目，确认直接进入战斗。
2. 同时按 P1/P2 左右键，确认炮台独立旋转。
3. 同时长按 Space 和 Enter，确认两边连续开火且金币各自扣除。
4. 分别切换倍率，确认互不影响。

### E2E-02 捕获与归属

1. 让双方渔网覆盖同一鱼群。
2. 确认每条鱼最多奖励一次。
3. 确认奖励进入声明捕获玩家的金币和统计。

### E2E-03 救援与结果

1. 让 P1 首次真正耗尽，确认自动获得 30 金币。
2. 再次耗尽 P1，确认其进入“等待伙伴”。
3. P2 耗尽并处理完全部待结算射击。
4. 确认结果层并列显示双方统计，不显示胜负。
5. 按 R 或点击按钮，确认开始全新一局。

### E2E-04 Boss

1. 使用测试配置推进到 60 秒或合计 18 次捕获。
2. 确认 2 秒提示后只生成 1 个 Boss。
3. 确认 Boss 使用普通捕获流程且不触发保底必得。
4. 确认离场或捕获后 90 秒内不再次出现。

### E2E-05 PC/Web

1. Windows 构建在 1280×720 与 1920×1080 下完成 E2E-01。
2. 通过本地 HTTP 在 Chrome、Edge 打开 Web 构建。
3. 点击画布后完成 E2E-01，确认页面不滚动。
4. 首次交互后确认 BGM 与音效恢复。
5. 调整浏览器窗口，确认 HUD 不重叠、炮台保持可见。
