## 2. 输入语义

1. 左右瞄准按物理时间连续旋转，旋转速度 `100°/s`，限制在向上半圆。
2. 倍率动作只在 `just_pressed` 时循环切换 `1× → 2× → 5×` 或反向。
3. 开火动作在 `just_pressed` 时立即触发，持续按住后按 0.25 秒冷却重复触发。
4. 两位玩家的冷却、按键状态和输入启用状态完全独立。
5. PAUSED、RESULTS 或该玩家 exhausted 时忽略其玩法输入。
6. Web 画布获得焦点后必须阻止 Space、方向键和 Enter 的浏览器默认行为。

## 3. 显示契约

- 基础画布：`1280×720`。
- Stretch mode：`canvas_items`。
- Stretch aspect：`expand`。
- 炮台固定在底部约 20% 与 80% 横向位置，宽屏时保持对称。
- HUD 使用锚点和容器，不依赖机器绝对路径或固定桌面分辨率。
- 验收尺寸：`1280×720`、`1920×1080`、桌面宽屏浏览器窗口。
- MVP 最低目标窗口为 `1024×576`；更小窗口不做布局保证。

## 4. 渲染与导出

| Preset | Renderer | 输出 | 要求 |
|---|---|---|---|
| Windows Desktop | Compatibility | `build/windows/happy_fish.exe` | Debug 构建可运行 |
| Web | Compatibility/WebGL 2.0 | `build/web/index.html` | 单线程、本地 HTTP 运行 |

约束：

1. `project.godot` 声明 Godot 4.7 与 Compatibility，不使用 Forward Plus 专属特性。
2. `export_presets.cfg` 纳入项目；`build/` 与导出产物忽略。
3. Web 文件不得在导出后重命名。
4. Web 音频允许在首次用户键盘或鼠标交互后开始，不增加强制开始页。
5. Web 验收浏览器为当前稳定版桌面 Chrome 与 Edge；Firefox、Safari、手机浏览器为非验收项。

## 5. 启动与退出

- 配置唯一主场景，项目启动后直接进入 `RUNNING`。
- Escape 打开暂停层；Web 环境若浏览器接管 Escape，必须保留可点击暂停按钮。
- 关闭窗口或刷新 Web 页面不保存任何局内数据。
