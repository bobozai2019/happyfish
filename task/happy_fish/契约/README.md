## 冻结规则

1. Gate 1 前为 `draft`，允许 T01/T02 补充但不得改变已确认产品结论。
2. Gate 1 后为 `frozen`；字段、信号参数、输入动作、状态或概率公式的破坏性变更必须新增 ADR。
3. 契约文件只描述边界，不记录运行结果；实际证据写入 `../验收/`。
4. 若未来新增 HTTP API，必须先建立字段级 request/response/error 契约或生成并冻结 OpenAPI；当前不适用。
5. 若未来新增数据库或存档，必须单独定义 schema、版本迁移与兼容策略；当前不适用。
