状态：`frozen`（Gate 1，2026-08-08）

Owner：T02

## 1. `FishDefinition`

实现形式：继承 `Resource` 的 typed GDScript 类；每种鱼使用独立 `.tres`。

| 字段 | 类型 | 必填 | 默认 | 校验 | 说明 |
|---|---|---:|---|---|---|
| `id` | `StringName` | 是 | - | 非空且全局唯一 | 稳定资源标识 |
| `display_name` | `String` | 是 | - | 简体中文非空 | HUD 与统计名称 |
| `sprite_frames` | `SpriteFrames` | 是 | - | 至少含 `swim` 动画 | 可替换原型资源 |
| `collision_radius` | `float` | 是 | - | `> 0` | 生成圆形碰撞体 |
| `reward` | `int` | 是 | - | `> 0` | 捕获奖励与统计价值 |
| `base_capture_chance` | `float` | 是 | - | `(0, 1]` | 基础概率 |
| `spawn_weight` | `float` | 是 | - | 普通鱼 `> 0`，Boss 为 `0` | 普通池加权选择 |
| `speed_min` | `float` | 是 | - | `> 0` | 像素/秒 |
| `speed_max` | `float` | 是 | - | `>= speed_min` | 像素/秒 |
| `display_scale` | `float` | 是 | `1.0` | `> 0` | 视觉与碰撞比例 |
| `is_boss` | `bool` | 是 | `false` | - | Boss 调度标志 |

## 3. `PlayerState`

实现形式：运行时 typed `RefCounted`；禁止序列化为本地存档。

| 字段 | 类型 | 初始值 | 约束 |
|---|---|---|---|
| `player_id` | `int` | `1` 或 `2` | 创建后只读 |
| `coins` | `int` | `120` | 不得小于 0 |
| `current_cannon_level` | `int` | `0` | 指向 1× 配置 |
| `rescue_used` | `bool` | `false` | 每局只可变为 `true` 一次 |
| `is_exhausted` | `bool` | `false` | 只由单局状态机写入 |
| `empty_net_streak` | `int` | `0` | 捕获后重置 |
| `capture_count` | `int` | `0` | 只增不减 |
| `capture_value` | `int` | `0` | 累加奖励值 |
| `largest_capture_id` | `StringName` | 空 | 记录最大价值鱼 |
| `largest_capture_value` | `int` | `0` | 与 id 同步更新 |
| `pending_resolution_count` | `int` | `0` | 发射加一，渔网完成减一，不得为负 |

## 4. 资源目录约束

1. 所有 `.tres`、图像、音频和字体必须位于 `resources/`。
2. `resources/` 及每个子目录必须有 `index.md`。
3. 同一资源层级只能放子目录或普通资源文件，`index.md` 与 Godot 元数据例外。
4. 所有引用必须使用 `res://`，不得写绝对路径。

## 5. Gate 1 校验

- 所有资源能被 `ResourceLoader` 加载。
- `id` 无重复，普通鱼恰好 8 种，Boss 恰好 1 种。
- 炮台倍率恰好为 1/2/5，字段值与本契约一致。
- 字段异常时测试必须失败并给出资源路径。
