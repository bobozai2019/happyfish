# 捕鱼达人双人原型决策记录

文档角色：`decision_record`

## ADR-001：PC 与桌面 Web 采用统一 Compatibility 渲染

- 日期：2026-08-08
- 状态：accepted
- 背景：项目当前声明 Forward Plus，但首版必须支持桌面 Web。
- 决策：项目切换到 Compatibility；交付 Windows 和桌面 Chrome/Edge 本地 Web 构建，Web 使用单线程导出。
- 影响：T01、T07、T08；美术和特效不得依赖 Compatibility 不支持的高级渲染特性。
- 后续：手机版和线上托管为 vNext。

## ADR-002：面向低龄儿童的本地双人同屏

- 日期：2026-08-08
- 状态：accepted
- 背景：目标玩家为低龄儿童，首版重点验证核心循环。
- 决策：两名玩家使用同一键盘；P1 为 A/D、W/S、Space，P2 为方向键、Enter；双方操作对称、数据独立。
- 影响：T01、T03、T05、T06、T08。
- 后续：手柄、鼠标瞄准和触控输入不进入 MVP。

## ADR-003：范围概率捕获与隐藏保底

- 日期：2026-08-08
- 状态：accepted
- 背景：需要保留经典捕鱼随机刺激，同时降低儿童连续失败的挫败。
- 决策：渔网范围内每条鱼独立概率判定；有效空网累计个人保底，3/5 次增加概率，7 次保证捕获最低价值非 Boss 鱼。
- 影响：T02、T03、T05 与自动测试。
- 后续：Boss 永不进入必得判定；改变公式必须新增 ADR。

## ADR-004：独立金币、一次救援和无输家结算

- 日期：2026-08-08
- 状态：accepted
- 背景：用户选择玩家金币独立，同时要求儿童友好。
- 决策：每人初始 120 金币；首次真正耗尽救援 30；第二次耗尽后等待；双方耗尽后并列展示统计，不宣布胜负。
- 影响：T05、T06、T08。
- 后续：不保存最高分或跨局成长。

## ADR-005：内容量与 Boss 形态

- 日期：2026-08-08
- 状态：accepted
- 背景：用户选择 8 种普通鱼加 Boss，但不加入特殊技能。
- 决策：Boss 为稀有高价值鲸鲨，与普通鱼共享捕获规则，不进入独立阶段；普通鱼上限 20。
- 影响：T02、T04、T07。
- 后续：技能鱼、Boss 血条和关底战均为 vNext。

## ADR-006：无服务端、存档与变现

- 日期：2026-08-08
- 状态：accepted
- 背景：首版是快速原型，且面向低龄儿童。
- 决策：不实现 HTTP API、数据库、账号、存档、广告、付费、真实货币或在线服务。
- 影响：全局范围；契约以 Godot 内部资源、信号和状态机为边界。
- 后续：若未来新增外部接口，必须先单独冻结 API 与数据契约。

## ADR-007：默认采用推荐选项

- 日期：2026-08-08
- 状态：accepted
- 背景：用户明确要求后续所有选择采用推荐项。
- 决策：对不扩大授权、非破坏性且有安全默认值的后续选择直接采用推荐方案，不暂停执行询问。
- 影响：所有任务调度。
- 后续：新增外部权限、破坏性操作或无安全默认值时仍需用户确认。
