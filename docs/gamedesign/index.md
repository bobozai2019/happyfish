# Happy Fish 游戏设计文档

本目录描述当前已经实现的单人/本地双人捕鱼原型，供策划、开发、美术和测试共同查阅。

## 文档导航

| 文档 | 内容 |
|---|---|
| [游戏设计总览](游戏设计总览.md) | 产品定位、体验目标、核心循环、单局流程和范围边界 |
| [玩法与数值](玩法与数值.md) | 单人鼠标/键盘、双人键盘、炮台、鱼类、捕获概率、保底、经济和 Boss 规则 |
| [内容与表现](内容与表现.md) | 场景、角色、UI、反馈、音频、文案和平台表现 |

## 文档口径

- 本目录记录“玩家看到和感受到什么”，用于理解和扩展游戏内容。
- 已冻结的模式、输入与单局约束，以 [`task/happy_fish_modes/契约/`](../../task/happy_fish_modes/契约/README.md) 为最终依据；未被增量替代的鱼类与概率边界继续沿用历史契约。
- 实际通过情况与截图，以 [`task/happy_fish_modes/验收/`](../../task/happy_fish_modes/验收/README.md) 为准。
- 后续若修改概率、奖励、炮倍、救援或 Boss 节奏，应先更新决策记录和契约，再同步本目录。
