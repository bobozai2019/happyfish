# 游戏设计总览

## 1. 游戏概念

《Happy Fish》是一款面向低龄儿童的单人/本地双人同屏捕鱼原型。玩家先选择单人捕鱼或双人同乐：单人可用鼠标或键盘控制中央炮台，双人共享海底竞技场并使用两套固定键位。

游戏强调轻松上手、一起游玩、即时反馈和低挫败感，不设置胜负、淘汰、付费或长期成长。启动后先进入模式选择，确认后才创建战斗。

## 2. 目标体验

### 2.1 体验支柱

1. **一人轻松、两人同乐**：单人提供直观鼠标操作，双人保持同屏合作氛围与独立资源。
2. **简单易懂**：方向、换档、开炮三类操作即可完成完整游戏循环。
3. **随机惊喜**：每条鱼独立进行概率捕获，高价值鱼和鲸鲨带来期待感。
4. **儿童友好**：个人隐藏保底、一次金币救援和无输家结算降低连续失败的挫败。
5. **明快反馈**：高饱和美漫卡通画面、金币飘字、短特效、音效和循环音乐共同强化命中与捕获。

### 2.2 目标玩家

- 主要玩家：能够使用鼠标或键盘基础按键的低龄儿童。
- 游玩关系：独自短局，或兄弟姐妹、朋友、亲子本地同玩。
- 单局特征：无需账号、存档或联网，可随时开始和重新开始。

## 3. 核心循环

```text
观察鱼群
   ↓
调整炮台方向与炮倍
   ↓
发射子弹并消耗金币
   ↓
命中后展开范围渔网
   ↓
逐鱼进行概率捕获
   ↓
获得金币、统计与视听反馈
   ↓
继续追逐普通鱼或等待鲸鲨 Boss
```

炮倍同时影响单发成本、捕获概率倍率和渔网范围。低炮倍适合持续尝试，高炮倍消耗更大，但更容易覆盖和捕获高价值目标。

## 4. 单局流程

### 4.1 开始

- 游戏启动后进入模式选择；未确认前不生成鱼、不推进计时、不播放战斗 BGM。
- 单人默认选择鼠标，也可选择 P1 键盘；双人固定使用双键盘。
- 每名 active player 各有 120 金币，默认使用 1× 炮台。
- 普通鱼持续从预制曲线路径进入场景，场上普通鱼最多 20 条。

### 4.2 进行

- 单人鼠标通过指针瞄准、左键或 HUD 按钮开炮，并用 `－/＋` 换挡；单人键盘复用 P1 按键。
- 双人可独立旋转、切换 1×/2×/5× 炮倍、单发或长按连发。
- 子弹命中第一条鱼时在命中位置展开渔网，对范围内每条可捕获鱼独立判定。
- 捕获奖励只归属于成功声明该鱼的玩家，同一条鱼不会被双方重复奖励。
- 有效空网会推进该玩家自己的隐藏保底；捕获任意鱼后保底清零。

### 4.3 高潮

- 开局满 60 秒或 active players 达到捕获阈值时触发鲸鲨警告：单人 10 条，双人累计 18 条。
- 警告持续 2 秒，随后鲸鲨 Boss 进入场景。
- 鲸鲨是稀有高价值目标，但仍使用普通捕鱼规则，不进入独立 Boss 战，也没有血条。

### 4.4 耗尽与救援

- 玩家金币为 0 且所有已发射对象结算完毕，才算真正耗尽。
- 第一次真正耗尽会自动获得 30 救援金币并继续游戏。
- 单人第二次真正耗尽后直接进入个人结果；双人耗尽的玩家显示“等待伙伴”，直到双方均耗尽。

### 4.5 结果与重开

- 所有 active players 都第二次耗尽，且没有待结算射击时进入结果界面。
- 单人展示个人捕获数量、总价值和最大鱼；双人并列展示双方统计，不评选冠军或失败者。
- “再来一局”保留当前模式和单人操作方式；“返回模式选择”销毁当前战斗并清空运行状态。

## 5. 游戏状态

| 状态 | 玩家体验 | 可用操作 |
|---|---|---|
| `RUNNING` | 鱼群游动、炮台可用、捕获正常结算 | 瞄准、换档、开炮、暂停 |
| `PAUSED` | 战斗冻结并显示友好暂停层 | 继续游戏、重新开始 |
| `RESULTS` | 停止生成和射击，展示个人或双人并列统计 | 再来一局或返回模式选择 |

应用层另有 `MODE_SELECT` 与 `PLAYING` 两态；暂停与结果仍属于战斗单局状态，不进入应用层枚举。

## 6. MVP 范围

### 当前包含

- 启动模式选择、单人捕鱼和本地双人同屏。
- 单人鼠标/键盘切换、鼠标 HUD 操作按钮；双人固定双键盘。
- 8 种普通鱼与 1 种鲸鲨 Boss。
- 三档炮倍、范围渔网、概率捕获和个人隐藏保底。
- 独立金币、一次救援、单人个人结果、双人等待伙伴和友好并列结算。
- 简体中文 HUD、暂停、结果、基础特效、音效与循环 BGM。
- Windows 构建和桌面 Chrome/Edge 本地 Web 构建。

### 后续候选

- 手柄、触控、移动端安全区、按键重映射与鼠标灵敏度。
- 冰冻、锁定、炸弹鱼、连锁技能与更多 Boss 机制。
- 图鉴、炮台解锁、永久货币、设置、存档和更多场景。

### 明确不包含

- 在线多人、账号、服务器、排行榜和云存档。
- 商店、广告、充值、真实货币或任何购买入口。
- 账号式主菜单、独立教程页和血条式 Boss 战。
