# 内容与表现

## 1. 场景构成

游戏使用单个 2D 海底竞技场作为完整原型场景：

- 中央区域保持开阔，用于鱼群穿行、子弹飞行和渔网反馈。
- 珊瑚、岩石和海草集中在画面边缘，形成天然画框，不遮挡主要玩法区域。
- 单人炮台固定在底部中央；双人炮台固定在底部约 20% 与 80% 的横向位置，宽屏下保持对称。
- 鱼群从场景两侧沿多条曲线路径进入、穿过并离场。

基础画布为 `1280×720`，使用响应式锚点和容器适配 `1920×1080` 与桌面宽屏窗口。MVP 最低目标窗口为 `1024×576`。

## 2. 美术方向

### 2.1 统一风格

- 美漫卡通、鲜明粗轮廓和夸张比例。
- 高饱和蓝色海底背景，暖色与冷色玩家标识形成对比。
- 角色使用赛璐璐式明暗，保持儿童友好而非写实或凶猛。
- 捕获特效简短、明亮，不长时间遮挡鱼群或另一名玩家视线。

### 2.2 角色层级

- 常见小鱼体型小、色彩鲜亮、移动较快。
- 中高价值鱼逐步增加体型、轮廓辨识度和视觉稀有感。
- 金龙鱼使用金色建立稀有普通鱼识别。
- 鲸鲨 Boss 体型最大、速度较慢，通过预告和独特音效建立登场感，但外观保持温和。

## 3. 战斗 HUD

| 区域 | 显示内容 | 表现要求 |
|---|---|---|
| 左上 P1 | 玩家 1、暖阳炮台、金币、炮倍、按键提示、状态反馈 | 暖色标识，左对齐 |
| 右上 P2 | 玩家 2、海蓝炮台、金币、炮倍、按键提示、状态反馈 | 冷色标识，右对齐 |
| 顶部中央 | 暂停入口、Boss 与全局提示 | 不遮挡主要鱼群区域 |
| 世界空间 | 金币飘字、渔网、命中和捕获短特效 | 与实际奖励一一对应 |

单人只显示 P1 面板；鼠标模式在底部提供 `－`、`开炮！`、`＋` 三个大点击区，键盘模式隐藏这些按钮。按钮不得遮挡炮口或中央鱼群区域。

金币和倍率采用图标加文字，不只依靠颜色传达信息。全部玩家文案使用简体中文和积极语气。

## 4. 状态界面

### 4.1 Boss 提示

- 在鲸鲨出现前显示醒目中文提示和 Boss 图标。
- 配合独立提示音，持续 2 秒。
- 不展示血条、阶段名称或强制操作。

### 4.2 救援与等待

- 首次耗尽显示对应玩家“救援金币 +30”，短暂出现后自动消失。
- 第二次耗尽显示“等待伙伴”，避免“破产”“淘汰”“失败”等负面措辞。

### 4.3 暂停层

- 主标题为“已暂停”。
- 提供“继续游戏”和“重新开始”。
- 单人显示鼠标/键盘即时切换；双人只显示固定双键盘说明。
- 提供“返回模式选择”，确认后结束当前单局。
- 使用半透明遮罩压暗战斗画面，但仍保留场景上下文。

### 4.4 结果层

- 单人显示个人捕获数量、总价值和最大鱼；双人并列显示双方统计。
- 不计算或显示赢家、输家、排名或比分压制关系。
- 提供清晰的重新开始按钮，并支持 `R` 键。

## 5. 反馈设计

### 5.1 发射

- 按下开火键立即响应，炮口、子弹和开炮音效同步出现。
- 两名玩家可通过轻微声像或音高差异区分，但整体音量保持平衡。
- 金币不足时自动降到可支付档位；完全无法开炮时不产生虚假射击反馈。

### 5.2 命中与张网

- 子弹首次命中鱼后迅速展开圆形渔网。
- 网的视觉尺寸随 1×/2×/5× 炮倍增加，与实际查询半径一致。
- 张网音效和短特效告诉玩家本次判定已经发生，即使没有捕获也保留操作反馈。

### 5.3 捕获

- 成功捕获触发金币飘字、捕获音效和短动画。
- 多鱼捕获可同时显示多个奖励，但限制同帧音效重叠，避免爆音。
- 同一条鱼只播放一次捕获反馈，并只为实际归属玩家增加金币与统计。

## 6. 音频内容

| 类别 | 用途 |
|---|---|
| 循环 BGM | 维持轻快海底氛围，允许长时间重复播放 |
| 开炮音效 | 提供即时输入确认，可区分两名玩家 |
| 命中/张网音效 | 标记渔网判定时机 |
| 捕获音效 | 强化获得金币和成功感 |
| Boss 提示音 | 建立鲸鲨即将出现的期待 |
| 按钮音效 | 暂停、继续、重开等界面反馈 |

桌面 Web 受浏览器自动播放策略限制，BGM 和音效在首次画布键盘或鼠标交互后解锁。模式选择本身不创建战斗或播放战斗 BGM。

## 7. 平台与启动体验

- Windows：双击项目根目录 `启动游戏.bat`，启动已导出的 `build/windows/happy_fish.exe`，先选择单人或双人。
- Web：通过本地 HTTP 服务打开 `build/web/index.html`，验收浏览器为桌面 Chrome 与 Edge。
- 游戏不请求账号、网络服务、存储权限或支付信息。
- 关闭窗口或刷新 Web 页面不会保存本局数据。

## 8. 内容扩展原则

后续新增内容应保持以下边界：

1. 新鱼优先提供清晰轮廓、独特颜色和明确价值定位，避免只做数值换皮。
2. 新技能必须让两位玩家都能理解其范围和归属，不能破坏独立金币与原子捕获规则。
3. 新 Boss 可以增加预告和行为变化，但儿童友好、无输家结算仍是核心体验。
4. 新 UI 不应挤占中央鱼群区域，也不得加入未经决策确认的商店、广告或付费入口。
5. 美术和音频资源继续统一存放在 `resources/`，使用 `res://` 引用并遵循项目资源索引规则。
